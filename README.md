# opencode-goal

Persistent, host-verified goal mode for [OpenCode 2](https://opencode.ai). Write a structured goal contract, start it, and the plugin keeps the session working until the host — not the model — proves every criterion.

> Status: pre-release (v0.1 in progress). The engine, verification pipeline and end-to-end tests are done; the TUI and the bundled `write-goal` skill are being finished. See [docs/HANDOFF.md](docs/HANDOFF.md).
